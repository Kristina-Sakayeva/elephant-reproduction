
# When Models Vanish: The Reproduction Window in LLM Behavior Research

This repository contains the code, analyses, and results associated with When Models Vanish: The Reproduction Window in LLM Behavior Research.

The project conducts an end-to-end reproduction of ELEPHANT, a benchmark for measuring social sycophancy in large language models. It examines how changes in model availability, model versions, evaluator identity, prompts, and implementation choices affect the reproducibility of behavioral LLM research.

This repository is currently being organized and documented. Additional reproducibility details will be added as the release is finalized.
